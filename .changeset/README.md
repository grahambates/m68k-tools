# Changesets

Pending release notes live here as Markdown files, one per change, each naming the packages it affects and their semver bumps. Add one with `pnpm changeset`.

The step-by-step release process, including versioning, publishing to npm and to the VS Code Marketplace, is in the [Releases section of the root README](../README.md#releases). Name the VS Code extensions in a changeset when a release should ship a new version of one.
