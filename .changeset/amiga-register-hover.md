Document Amiga custom chip registers and flags on hover when a symbol is named as the Amiga includes name them, in either case: `intena` or `INTENA`, numbered registers such as `COLOR17`, pointer pairs such as `cop1lc`, and flags such as `DMAF_SPRITE` or `INTB_VERTB`. The hover gives the register's address and direction, what it does and its bits, with a link to its page in the Hardware Reference Manual. A value written to a named register is read against its bits, as `move.w #$8020,dmacon(a6)` or the copper list pair `dc.w DMACON,$8020`: which bits a set/clear register sets or clears, or which bits are on and what each field holds, with any bits it does not describe; standard flags the project does not define, such as `DMAF_SPRITE`, take the includes' values. ECS and AGA registers are covered too (BPLCON3, BPLCON4, FMODE, BEAMCON0, DIWHIGH, CLXCON2, DENISEID, bitplanes 7 and 8, the programmable sync registers and the UHRES registers), along with the bits ECS and AGA added to BPLCON0, BPLCON1, BPLCON2, BLTCON1, the sprite control registers, VPOSR and the colour registers, each labelled with the chip set that added it. Nothing is shown where the symbol's value is known and is not the register's offset or address, or the flag's value.
