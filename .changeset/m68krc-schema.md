Publish a JSON schema for `.m68krc.json` as `m68krc.schema.json`, for completion and validation of the project config. The VS Code extension bundles it; other editors can reference `https://cdn.jsdelivr.net/npm/m68k-lsp-server@0/m68krc.schema.json` through `$schema`.
